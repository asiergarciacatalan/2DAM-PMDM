1La regla de oro

  • Datos y acciones → .ts (variables, arrays, interfaces, métodos).
  • Lo que se ve → .html ({{ }}, botones, @if, @for).
  • En el .ts siempre this. delante de las variables. En el .html nunca.

.html
@for (plato of carta; track plato.nombre) {
  <p>{{ $index + 1 }}. {{ plato.nombre }}</p>

  • track es obligatorio. Si no tienes un campo único: track $index.
  • Borrar: (click)="borrar($index)" y en el .ts this.lista.splice(index, 1);
  • Tablas: fila de títulos fuera del @for, filas de datos dentro.

6Signals

NormalSignal
Crearn: number = 0;n = signal(0);
Leerthis.n / {{ n }}this.n() / {{ n() }}
Cambiarthis.n = 5;this.n.set(5);
Según el anteriorthis.n = this.n + 1;this.n.update(v => v + 1);
.ts
import { Component, signal, computed } from '@angular/core';

lista = signal<Alumno[]>([]);

anadir(a: Alumno) {
  this.lista.update(l => [...l, a]);
}

borrar(index: number) {
  let copia = [...this.lista()];
  copia.splice(index, 1);
  this.lista.set(copia);
}

total = computed(() => {
  let suma = 0;
  for (let a of this.lista()) {
    suma = suma + a.precio;
  }
  return suma;
});
Con signals el @for lleva paréntesis: @for (a of lista(); track $index). Nunca hagas push directamente al array del signal.

10Ciclo de vida

constructor → ngOnChanges → ngOnInit → ngAfterViewInit → ngOnDestroy

  • ngOnInit: lo que se hace al empezar (cargar datos, arrancar un temporizador).
  • ngOnDestroy: limpiar al salir (clearInterval).

★Cómo hacer el examen

  1. 5 minutos en papel: qué páginas, componentes, interfaces y variables vas a necesitar.
  2. Primero el esqueleto: rutas y menú funcionando, aunque las páginas estén vacías.
  3. Copia de tus ejercicios con el índice y cambia todos los nombres.
  4. Terminal y consola (F12) siempre a la vista. Un error rojo se arregla en el momento.
  5. Últimos 10 minutos: prueba todos los botones, comprueba el @empty, borra console.log e imports que no uses.
Si algo falla, casi siempre es una de estas cinco cosas:
  • Falta un this.
  • Falta algo en imports
  • Lees un signal sin ()
  • La ruta no está en app.routes.ts
  • Copiaste un bloque y no le cambiaste los nombres

Mucha suerte. Vas preparado.
