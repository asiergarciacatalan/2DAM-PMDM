# 📱 Programación Multimedia y Dispositivos Móviles — 2º DAM

![Angular](https://img.shields.io/badge/Angular-DD0031?logo=angular&logoColor=white) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white) ![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?logo=tailwindcss&logoColor=white)

Proyectos de la asignatura **PMDM** del ciclo DAM: aplicaciones web con **Angular** (componentes standalone, rutas, comunicación padre-hijo) y maquetación con **Tailwind CSS**.

## 📂 Proyectos

| Proyecto | Qué practica |
|---|---|
| [`Angular/DAM-proyecto1angular`](Angular/DAM-proyecto1angular) | Primer proyecto: estructura con cabecera, páginas y pie |
| [`Angular/DAM-proyecto2`](Angular/DAM-proyecto2) | Rutas y renderizado en servidor (SSR) |
| [`Angular/DAM-proyecto03`](Angular/DAM-proyecto03) | Navegación y componentes hijo |
| [`Angular/DAM-proyecto04`](Angular/DAM-proyecto04) | Ejercicios y respuestas con componentes |
| [`Angular/Proyecto_1`](Angular/Proyecto_1) | Comunicación entre componentes padre e hijo (`@Input` / `@Output`) |
| [`Angular/Proyecto2`](Angular/Proyecto2) | Layout con header y aside + Tailwind |
| [`Angular/proyecto3`](Angular/proyecto3) | Layout responsive con menú lateral para móvil |
| [`Tailwind-Admin-Dashboard`](Tailwind-Admin-Dashboard) | Panel de administración en HTML + Tailwind adaptado a partir de una plantilla de código abierto (ver su `LICENSE`) |

## ▶️ Cómo ejecutar un proyecto Angular

```bash
cd Angular/proyecto3
npm install
ng serve
```
Y abrir `http://localhost:4200`.
